Porto Running Guide

Website Planning Document

Site Name

Porto Running Guide

I chose this name because the website will help people who live in or visit Porto find useful running routes, beginner tips, and practical information for outdoor running. The name is simple, clear, and directly connected to the purpose of the website.

Optional domain: portorunningguide.com

Site Purpose

The purpose of this website is to provide a simple guide for runners in Porto. The site will include suggested running routes, basic training tips, safety recommendations, and a contact or interest form for visitors who want more information or want to join local running activities.

Scenarios

  • What are the best places to run in Porto for beginners?
  • Where can I find a safe and scenic running route near the Douro River?
  • How can I contact the organizer or receive updates about running activities?

Color Schema

The color schema is inspired by the city of Porto, outdoor exercise, and the Douro River.

Primary Color

#0f4c5c

Used for headers, footer, and main navigation areas.

Secondary Color

#e36414

Used for buttons, highlights, accents, and important visual details.

Background Color

#f5f5f5

Used for the page background to keep the design clean and readable.

Typography

The website will use two fonts from Google Fonts:

  • Montserrat Bold: used for main headings and section titles.
  • Roboto Regular and Bold: used for body text, paragraphs, lists, and smaller interface text.
